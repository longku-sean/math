115 翰林國二上（第3冊 · 1-1～4-3）重點速查

第1章 多項式與乘法公式 (1-1 ～ 1-3)
  • 1-1 多項式與加減法：x 不可在分母、根號或絕對值內；去括號遇減號全體變號，同類項合併係數。
  • 1-2 多項式乘除：被除式 ＝ 除式 × 商式 ＋ 餘式（餘式次數必小於除式次數，缺項要補 0）。
  • 1-3 乘法公式：(a+b)2 = a2+2ab+b2；(a-b)2 = a2-2ab+b2；(a+b)(a-b) = a2-b2。
第2章 二次方根與畢氏定理 (2-1 ～ 2-3)
  • 2-1 二次方根意義：正數 a 的平方根為 ±√a；易錯公式：√(a2) = |a|（必為非負數）。
  • 2-2 根式運算：最簡根式內無平方因數、分母無根號；利用 (√a+√b)(√a-√b)=a-b 有理化分母。
  • 2-3 畢氏定理：a2+b2=c2；常見畢氏數 (3,4,5)、(5,12,13)、(7,24,25)、(8,15,17)；斜邊上的高 = (a×b)/c；兩點距離 = √[(x1-x2)2+(y1-y2)2]。
第3章 因式分解 (3-1 ～ 3-2)
  • 3-1 提公因式與公式：變號技巧 (b-a) = -(a-b)，(b-a)2 = (a-b)2；優先提公因式再套用平方差或完全平方式。
  • 3-2 十字交乘法：x2+(p+q)x+pq = (x+p)(x+q)；頭拆兩邊、尾拆兩邊，交叉相乘和等於中間項。
第4章 一元二次方程式 (4-1 ～ 4-3)
  • 4-1 因式分解求解：若 A×B = 0，則 A=0 或 B=0。易錯：方程式兩邊絕不可隨便同除未知數 x，否則會漏掉 x=0 的解！
  • 4-2 配方法與公式解：判別式 D = b2-4ac（D>0 兩相異實根、D=0 重根、D<0 無實數解）；公式解 x = [-b ± √(b2-4ac)] / (2a)。
  • 4-3 應用問題：解出兩根後務必代入原題意檢驗合理性（如邊長、人數、路寬須為正數且不超過原邊長）。
